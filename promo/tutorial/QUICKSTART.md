# 给第一次使用者的操作速查

先选一条路线：有 Windows 程序就按第一部分做；没有合适的程序版本才看最后的源码运行。`.env` 是可选配置方式，不是额外必须完成的步骤。

## 1. 下载并打开

打开[项目发布页](https://github.com/weixiao-czy/data_base_agent/releases)，在发布记录的 Assets 里找 `LiteratureSearchAgent.exe`。`Source code (zip)` 是源码，不能当 EXE 双击运行。

在“文档”中新建“文献检索助手”文件夹，把程序放进去再双击。如果下载的是项目发布的程序压缩包，先解压。新版源码与发布包可能不同步，缺少“最近地图”等按钮时先核对版本。

## 2. 配置模型：准备配套的三项信息

先登录你有权限使用的 **OpenAI 兼容模型服务商**的 API 控制台。在密钥管理中创建密钥，从该平台的接口文档和模型列表取得地址与模型 ID。不同平台的入口不同，教程画面是通用示意；聊天网站的密码不能当密钥。

| 设置项 | 填什么 | 不要填什么 |
| --- | --- | --- |
| API Key | 你创建的模型调用密钥 | 登录密码、教程占位值、`Bearer` 前缀 |
| Base URL | 同一平台文档中的完整 API 基础地址 | 聊天网页地址、其他平台的地址 |
| 模型 | 同一平台支持且你的账号可调用的模型 ID | 自己起的名字、无权限的模型 |

打开程序左下角“设置”→“LLM 配置”，填完三项后保存。默认交大地址只适用于有该平台权限的账号，不是所有人都能直接使用的通用接口。密钥框出现圆点是正常隐藏。

SciMaster 是另一项可选检索服务。没有它的专用密钥，先留空；主线使用 Crossref / arXiv。不要把模型密钥复制进 SciMaster 栏。

## 3. 先验证，再开始

“就绪”只说明读到了配置，不代表服务器验证成功。新建对话，发送：

> 我想研究大模型如何帮助文献检索，先做一篇方法综述。

留意“模拟模式”或“LLM 调用失败”提示。程序有规则回退，有回复不一定代表真实模型调用成功。密钥或权限错误检查三项配置；模型不存在检查准确 ID；超时检查 API 地址和网络；额度或限流错误按平台提示处理。

## 4. 按这个顺序操作

1. 新建对话，输入“研究主题 + 想做什么”。
2. 点选接近的研究方向；不合适就选“其他”并补充。想提前生成计划，可在澄清时选择“跳过”。
3. 阅读“需求翻译卡”，检查研究问题、关键词、不确定性。跑偏就点“需要调整（请说明）”。
4. 在计划确认菜单点“以树形图查看文献结构”，等待生成。
5. 从“综述与奠基”开始读树图，再看“核心方法”“数据集与评测”等分支。点节点展开/折叠，滚轮缩放，拖动空白处移动，用“适应窗口”恢复视野。
6. 搜索关心的节点或文献标题，点击文献读右侧摘要。树图表示主题层级，不表示论文引用关系。
7. 点右上角“返回对话”，然后“确认，开始检索”。返回后也可重新生成树图或返回调整计划。
8. 读结果摘要，点击可用的论文标题或来源链接核对原始信息。结果不合适就“细化检索（开始新对话）”。

## 5. 保存并下次接着看

- 顶部“导出翻译卡”保存计划；“导出结果”保存已有论文清单，建议先选 `.txt`。
- 地图另外自动保存为 `.html`、`.md`、`.json`，在 EXE 旁或源码项目下的 `output/maps`。
- 重新打开地图：聊天页“最近地图”，或“导入树形图文件”选择以前生成的 HTML。
- 已有 HTML 可以离线浏览。新检索和新地图生成仍需要网络。
- 内嵌预览失败时，可以使用“在浏览器打开”或打开地图 HTML；缺少 WebEngine 时程序也可能直接转到浏览器。

## 可选：用 .env 配置

EXE 用户把 `.env` 放在程序旁边；源码用户放在含 `gui_launcher.py` 的项目目录里。记事本另存为时选“所有文件”，确认没有多出 `.txt`，编码用 UTF-8。下面只是模板，尖括号内容全部替换为自己的值：

```dotenv
OPENAI_API_KEY=〈你的真实模型密钥〉
OPENAI_BASE_URL=〈同平台的接口地址〉
OPENAI_MODEL=〈该平台可用的模型ID〉
SCIMASTER_API_KEY=
```

修改后完全退出并重新打开程序。设置页的非空值优先；想让某项读取环境文件，清空设置里的对应项并保存。已有系统环境变量也可能覆盖 `.env`。一般选一种配置方式就够了。

## 可选：Windows 源码运行

从[项目主页](https://github.com/weixiao-czy/data_base_agent)点 Code → Download ZIP，解压。进入能看到 `gui_launcher.py`、`requirements.txt` 的目录。

从 [Python 官网](https://www.python.org/downloads/windows/)安装 Python 3.12 的 Windows 安装器，安装时勾选添加到 PATH；安装后重新打开终端。此版本是本教程选用的运行路线，不表示最新版本。

在项目文件夹空白处右键打开终端或 PowerShell，一次执行一条，等结束后再执行下一条：

```powershell
python --version
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe gui_launcher.py
```

第一条应显示 Python 3.12.x。若显示其他版本或找不到命令，先核对 Python 安装与 PATH。安装依赖报错时先处理错误，不要跳过。无需执行 `Activate.ps1`。

出现 GUI 后，接回前面的 API 配置步骤。以后仍从这个目录执行最后一条命令启动。缺少 QtWebEngine 时检查依赖安装；已生成 HTML 仍可用浏览器打开。
