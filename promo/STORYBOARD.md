# 分镜脚本｜文献检索 Agent · 文献地图篇

版本：2026-10-22。目标：让观众从「帮助我搜论文」进一步理解「帮助我看清研究领域与阅读路径」。在原一分钟片的风格与功能叙事上扩展，文献地图成为中后段主展示。

**84 秒，1920×1080，30 fps，2520 帧，120 BPM。** 1 拍 = 15 帧，1 小节 = 60 帧。时间线以 `src/film.json` 为准。以下帧区间均为左闭右开；最终可见帧是 2519。音乐与文字驱动，无旁白，后续模型无需生成配音。

## 统一视听规则

- 外层品牌画面：墨绿 `#111916`、暖白 `#F3F2EB`，荧光绿 `#D6F78A` 强调价值，珊瑚橙 `#FF855F` 强调点击和进度。
- 图内使用接近真实功能的白底、蓝/青/紫等维度颜色，区分主题、研究维度、检索方向和文献。不是引文网络。
- 中文字体：Microsoft YaHei → PingFang SC → Noto Sans SC。字体必须实际可用；文字为 DOM / SVG 原生文字，禁止转成 AI 生成的文字图片。
- 原片大字、弹性入场、立体卡片、底部进度线保留。地图段让画布占据主体，避免一边看小图一边读大量文案。
- 固定品牌角标安全边距 115 px。新地图窗口 x=115、y=295、w=1690、h=650；下方功能字幕 y=982。
- 非结尾场景最后 9 帧做上推色块转场，切点均在拍点。地图内部操作连续发生，禁止每次点击都额外加全屏转场。
- 演示文献标题带「示例」，不添加虚构 DOI、作者、引用次数或篇数。生成等待已压缩展示，保留这一提示。

## 镜头 09 与结尾的时间点

- 70.50 秒开始显示地图自动保存格式；73.50 秒出现「线索已保存，继续探索」。
- 76 秒进入结尾；约 78.5 秒前 CTA、地址和功能标签全部入场，随后停留约 5 秒。
- 树形图的 HTML 可离线浏览；本片不承诺离线生成新检索结果，不承诺真实引用关系或实时生成速度。

## 音乐脚本

曲名沿用 **A Clearer Question**；原创算法合成，无人声。D 大调，Dmaj9 / Aadd9 / Bm7 / Gmaj9，120 BPM。原版结构延展，不把原来的 60 秒文件机械循环。

| 时间 | 编曲 |
| --- | --- |
| 0–6 秒 | 电钢琴与柔和 pad，引入期待 |
| 6–22 秒 | 主旋律、贝斯、轻鼓与琶音逐步进入 |
| 22–32 秒 | 增加和声与立体声层次 |
| 32–42 秒 | 第一峰值：完整鼓组、较亮琶音 |
| 42–48 秒 | 入口操作 bridge：减少 kick，撤掉 snare，给状态文字留空间 |
| 48–58 秒 | 第二峰值：让树形结构展开具有推进感 |
| 58–60 秒 | 短暂减薄，聚焦折叠/展开交互 |
| 60–76 秒 | 保留节拍，旋律降低八度，兼顾搜索和摘要阅读 |
| 76–80 秒 | 撤去鼓与琶音，留和声与尾音 |
| 80–84 秒 | 解决和弦，最后 1.7 秒淡出 |

转场前有 0.55 秒柔和 sweep。选项、地图入口、分支、搜索、文献选择、返回对话和保存结果共 24 个轻音效事件；音效以代码事件表为准，不需要后续模型凭感觉得分镜时间。
